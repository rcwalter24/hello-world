# 《万物皆可算》——数学·物理·计算机之美 动画宣传片 构思稿

> 英文名:**The Source Code of Everything**
> 时长:约 3 分钟 | 画幅:16:9 / 1080p / 30fps | 风格:深色底、极简线条、发光几何
> 一句话:**从一个点出发,沿着一根线,爬完三门学科从小学到最前沿的全部台阶,最后发现它们是同一座山。**

---

## 1. 核心创意

**一条线,一路变形。** 全片只有一个视觉主角:一个发光的点 → 一条线 → 一个圆 → 波 → 曲面 → 网络 → 时空。
镜头永远在"缩放/穿越"中前进,像在爬一座山,每爬一层,难度和深度上升一档,但**视觉语言保持统一**,观众不会迷路。

**三色编码三门学科**(全片一致):

| 学科 | 颜色 | 意象 |
|---|---|---|
| 数学 | 金色 `#F5C451` | 结构、证明、图形 |
| 物理 | 青蓝 `#4CC9F0` | 运动、场、时空 |
| 计算机 | 品红 `#F72585` | 比特、算法、网络 |

三色开始时各走各的,越往深处越**缠绕、交汇**,结尾融成白光——这就是全片的主题:
**数学是语言,物理是内容,计算是过程;到了最深处,它们是同一件事。**

**四层台阶(字幕小标记)**:`基础 → 高中 → 大学 → 前沿`,让观众直观感到"我在往深处走"。

---

## 2. 分镜(共 7 幕,约 180 秒)

### 序幕 · 一个点(0:00–0:15)
- 黑屏,一个点亮起(数学:点)。点移动留下轨迹 → 线(几何)。线弯成圆。
- 旁白:*"一切,从一个点开始。"*
- 声音:单音,心跳般的低频脉冲。

### 第一幕 · 基础 · 数得清的世界(0:15–0:40)
- **数学**:圆展开成线段,长度 = π,数字 3.14159… 从线段上"滴落";勾股定理的面积拼图动画(a²+b²=c²)。
- **物理**:小球自由落体,频闪轨迹画出抛物线;苹果落下,月亮也在"落"(牛顿的一句话)。
- **计算机**:0 和 1 两个光点,组合成 `1011`,点亮一个灯泡 → 与/或/非门 → 一个加法器算出 1+1=10。
- 字幕:`基础`

### 第二幕 · 高中 · 圆里藏着波(0:40–1:10)
- **数学**:单位圆上的点匀速转动,右侧同步拉出正弦曲线(三角函数 = 圆的影子);随后 y=x² 的切线滑动,斜率实时显示(导数)。
- **物理**:两个点波源在水面上扩散圆环,干涉出双曲线条纹;单摆与弹簧,相位空间画出椭圆。
- **计算机**:二分查找——区间一次次减半,1 秒内找到 100 万个数中的目标;柱状图排序算法跳舞;递归画出谢尔宾斯基三角形。
- 字幕:`高中`

### 第三幕 · 大学 · 万物皆可分解(1:10–1:45)
- **数学**:**傅里叶级数**——一串旋转圆(本轮)首尾相连,末端画出一个方波,再画出一只小鸟/一个 π 符号;然后画面定格在 **e^{iπ}+1=0**,五个常数依次亮起。
- **物理**:**麦克斯韦方程组**——电场与磁场互相"接力",垂直交替向前传播,得出光速 c;光 = 波,波的形状 = 刚刚的正弦。
- **计算机**:**图灵机**的纸带与读写头缓缓移动;停机问题的"自指悖论"用一个吞掉自己尾巴的环表示;P vs NP:一座迷宫,"找出路"很难,"验证路"很快。
- 字幕:`大学`

### 第四幕 · 深处 · 弯曲、复杂、涌现(1:45–2:20)
- **数学**:**曼德博集合**无限放大(一次 20 秒的深潜镜头);拓扑:咖啡杯连续变形为甜甜圈;黎曼ζ函数零点沿临界线 Re(s)=1/2 一颗颗排开。
- **物理**:**广义相对论**——网格时空被质量压弯,光线沿弯曲轨迹绕行(引力透镜);**量子双缝**——粒子逐个打出,先是一片杂点,渐渐累积出干涉条纹。
- **计算机**:**神经网络**——节点网络在梯度下降中"找谷底",随后输出一张从噪声中浮现的图像(暗示生成式 AI);哈希 / 加密:一把大数分解的"锁"。
- 字幕:`大学之后`

### 第五幕 · 前沿 · 三条线开始缠绕(2:20–2:48)
三门学科不再各占一屏,画面变成**三色 DNA 式双螺旋 / 辫子**,每一个前沿话题都同时属于两三个学科:
- **量子计算**(物理 × 计算机):叠加态的比特球(布洛赫球)旋转,Shor 算法把大数拆成质因数。
- **AdS/CFT 全息原理**(物理 × 数学):圆盘内部的双曲空间(庞加莱圆盘、埃舍尔式镶嵌),边界上的"信息"决定了内部的引力。
- **朗兰兹纲领**(数学 × 数学):数论、几何、表示论三座岛屿之间架起桥梁。
- **黑洞信息 / 量子纠错码**(三者交汇):黑洞视界上的比特,纠错码与时空几何互相对应。
- **Curry–Howard 对应**:证明 = 程序 = 物理过程(用三个符号并排一闪而过)。
- 字幕:`前沿`

### 终幕 · 同一座山(2:48–3:00)
- 金、青、品红三条线终于拧成一束白光,回缩成——最初那个点。
- 旁白:*"数学是语言,物理是世界,计算是过程。……或者说,它们从来是同一件事。"*
- 片名淡入:**万物皆可算 · The Source Code of Everything**
- 最后一行小字:*"而你,才刚刚出发。"*

## 4. 制作方案(工具选择)

**已检查沙箱环境**:有 Node 22、Python 3.11、Playwright + Chromium、Playwright 自带 ffmpeg;**没有** LaTeX、Manim、numpy(可用 pip 装)。
因此**不选 Manim**(依赖 LaTeX/Cairo,装起来重),改用更轻、更可控、可直接分享的方案:

### 主方案:HTML5 Canvas/WebGL 动画 + 确定性逐帧渲染 → MP4

1. **引擎**:单文件 `index.html`,核心是纯函数 `render(t)`——给定时间 t 画出那一帧。
   - 2D 场景(几何、波、算法)用 Canvas 2D;
   - 曼德博深潜、时空弯曲、引力透镜等重计算场景用 WebGL 片元着色器。
2. **时间线**:每幕是一个模块 `scenes/actN.js`,导出 `{ duration, render(ctx, t) }`,总时间线只负责拼接与转场,便于单幕迭代。
3. **预览**:浏览器里直接实时播放,可拖动进度条、暂停、逐幕跳转。
4. **导出**:Playwright 无头 Chromium 逐帧调用 `render(t)` → 截图 → Playwright 自带 ffmpeg 合成 1080p30 MP4。**逐帧确定性渲染,不会掉帧**,重场景也不怕慢。
5. **音频**:先用 Python 程序化合成配乐(低频脉冲 + 随幕数逐步叠加的和声 pad,每幕节奏与画面对齐),旁白可后续换成真人/TTS 录音再 mux 进去。
6. **交付物**:`film.mp4`(成片)+ `index.html`(可交互网页版,可直接发布成 Artifact 分享)。

### 里程碑

| 阶段 | 内容 | 产出 |
|---|---|---|
| M0 | 引擎骨架、配色/字体/转场、导出管线打通 | 10 秒测试片 |
| M1 | 序幕 + 第一幕 + 第二幕 | 前 70 秒 |

| M4 | 配乐 + 旁白 + 混音 + 导出 | 成片 MP4 |
